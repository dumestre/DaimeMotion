# Daime Motion — frame direction

Um campo verde-escuro mineral com luz âmbar localizada: cinematográfico, preciso e acolhedor. A tipografia geométrica conduz a narrativa; a mono espaçada funciona como marcação de processo.

## Composition rules

- Manter o fundo escuro e as duas luzes radiais contidas; não usar gradiente linear em tela cheia.
- Usar o âmbar como linha de trajetória e ponto de resolução, sem competir com a palavra principal.
- Encerrar com a marca tipográfica centralizada e uma pausa legível.
- Preservar margem segura ampla e hierarquia de texto própria para vídeo.
